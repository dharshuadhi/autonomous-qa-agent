AUTONOMOUS QA AGENT

A test agent that runs the suite, heals its own locators when the UI changes, explains failures in plain English with an LLM, and files the bug itself. Built with Java 17, Selenium 4, Cucumber and an aspect-woven Allure reporter — running green in CI right now.
