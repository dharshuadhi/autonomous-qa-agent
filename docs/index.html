TRIAGE

Four bays. Zero waiting room.

Tap a bay to see what happens inside. Every stage runs autonomously — no on-call human required.

01
🧬

Generate

LLM drafts Cucumber scenarios from plain-English requirements.

An LLM reads the requirement doc and emits .feature files with realistic steps and data. A human reviews once — then the clinic takes over.
02
🤖

Execute

Selenium drives the real app in headless Chrome, step by step.

Page objects encapsulate every screen of the app. Steps run against the live site with explicit waits — SmartLocator.click() waits for clickability, scrolls into view, and falls back to JS clicks.
03
🩺

Heal

Broken locator? The agent switches to a fallback — mid-run.

Each element carries a primary locator plus a fallback chain. If the primary misses, SmartLocator walks the chain, logs a [SELF-HEALED] event, and the test continues. No rerun needed.
04
📋

Report

Allure charts, healing notes, and auto-filed bug tickets.

Every run emits an Allure report plus a HealingReport. Genuine failures get an RCA and an Azure DevOps bug with logs attached — the on-call wakes up to answers, not alerts.
